# Scope

- Status: Accepted
- Date: 2026-11-27

## Context

The project needs an agreed boundary for scope.

## Decision

**Both layers**: a deterministic *engineering layer* (workspace, checks, contracts, policy, run records) usable by any agent or human, plus a thin built-in *agent runner*.

## Consequences

Implementation must respect this boundary; changes require human agreement and a new decision.
