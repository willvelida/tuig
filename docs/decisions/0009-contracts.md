# Contracts

- Status: Accepted
- Date: 2026-11-27

## Context

The project needs an agreed boundary for contracts.

## Decision

Every task needs acceptance criteria mapped to executable checks, enforced by a traceability gate. Full EARS-style requirements (`WHEN … THE SYSTEM SHALL …`) are required only for feature-sized work.

## Consequences

Implementation must respect this boundary; changes require human agreement and a new decision.
